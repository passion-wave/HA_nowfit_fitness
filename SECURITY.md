# Security

Report vulnerabilities through the repository's private GitHub security-advisory channel:
<https://github.com/passion-wave/HA_nowfit_fitness/security/advisories/new>. Do not attach
credentials, cookies, CSRF values, complete account HTML, member identifiers or access-code images
to public issues.

The integration only permits HTTPS requests to `nowfit.memberarea.club` and rejects redirects to
another origin or to HTTP.
